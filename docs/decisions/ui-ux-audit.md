# 웹 데모 UI/UX 점검

## 표시와 조작

- 시그니처 색상, 로고, 시계와 아이폰 프레임을 유지한다. 웹 프레임은 최대 390×844px이며 작은 화면의 너비와 높이에 맞게 축소된다.
- 현금흐름은 가로 스크롤 없이 전체 기간을 보여준다. 예상 잔액은 초록 실선, 필요 비상금은 빨간 점선, 확정 현금은 회색 점선, 예상 변동 범위는 연한 초록 영역이다. 세로축에 0과 중간 눈금을 포함한다.
- 기본 선택은 예상 잔액이 가장 낮은 달이다. 그래프, 이전·다음 달 버튼, 펼쳐진 월별 목록에서 선택할 수 있고 선택한 달의 금액과 기준 미달 여부를 함께 표시한다. 월별 목록에는 금액·범위·확정 현금·비상금을 모두 보존한다.
- 검토에서 가구·금융·계획을 따로 수정할 수 있다. 결과의 입력 수정도 검토로 연결한다. 입력을 저장한 후 기존 입력 흐름을 따라 검토로 복귀한다.
- `시작`은 직접 입력 세션을 빈 값으로 초기화한다. `데모로 보기` 또는 데모 카드 선택 때만 예시값을 채우며, 직접 입력에서는 0·없음·아니오도 사용자가 명시한다.
- 대안 화면은 현재 상태와 각 대안의 금액·기간·실행 부담을 비교한다. 재확인용 그래프는 접어두고 필요할 때 펼친다. 대안·안전 적립의 결과 복귀와 근거의 이전 화면 복귀는 고정 하단 버튼으로 제공한다.
- 대안 카드는 현재 계획 대비 가장 적게 남는 돈의 증감액을 첫 지표로 표시한다. 12개월 뒤 금액·비상금 부족 기간·추가 비용은 보조 지표로 구분하며, 근거 화면의 중복 복귀 버튼은 하나로 합친다.
- 동의 및 선택 카드의 체크 상태를 웹 접근성 속성에 전달하고 Space 키 조작을 지원한다.
- 근거는 출처와 금액을 보존하면서 내부 필드명·규칙 식별자와 알려진 영문 코드를 한국어로 표시한다. 추가 입력이 없는 경우 빈 카드 대신 안내를 제공한다. 템플릿 출처를 검증 완료라는 뜻으로 과장하지 않는다.

## 검증 범위

Chrome의 로컬 웹 데모에서 시작, 동의, 시나리오, 가구, 금융, 계획, 검토, 결과, 대안, 안전 적립, 근거를 직접 조작했다. 기본 화면 크기와 320×740, 390×844 뷰포트에서 레이아웃을 확인했다.

- 과거 출산 예정월 차단, 천 단위 금액 표시, 입력값을 보존한 수정 경로
- 동의 Space 키 선택·해제에 따른 진행 버튼 상태
- 초산 맞벌이, 외벌이 전환, 한부모 기본 및 소득 지연 분기
- 그래프 월 이동, 마지막 달 이동 제한, 월별 목록과 도움말 펼침, 대안 화면의 독립적인 월 선택
- 적립 가능/보류 결과, 한국어 근거 표시 및 이전 화면 복귀

자동 검증은 TypeScript, ESLint, 변경 파일 Prettier, 전체 Jest 테스트와 Expo 웹 export를 사용한다. 차트 테스트에는 빈 응답, 단일 월, 0원, 음수, 월 이동과 카드 선택 동기화를 포함한다.

## 남은 검증 범위

실제 백엔드 연동 및 네이티브 기기 실행은 이번 웹 디자인 점검에 포함하지 않는다. 합성 데이터의 위험 부족액과 월별 잔액은 각각 응답값을 그대로 표시하며, 화면에서 서로를 역산하거나 임의 보정하지 않는다.

의존성 검사에서 high/critical은 없었지만 기존 Expo 의존성 경로의 moderate 13건이 보고됐다. 강제 수정은 Expo/Router의 하위 버전으로 바꾸는 변경이므로 이번 디자인 작업에 포함하지 않았다.
