# PARITY AI Mobile

Expo React Native and TypeScript mobile application for the PARITY AI PoC.

## Repository status

Initial repository setup is in progress. The application will consume types generated from the backend OpenAPI specification and will support mock, local API, and demo modes.

## Collaboration

Read [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request. Never place secrets in an `EXPO_PUBLIC_` environment variable because those values are included in the application bundle.
